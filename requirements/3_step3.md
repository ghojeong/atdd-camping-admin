# 3단계 - 인수 테스트와 리팩터링

## 요구사항

### 1. 레거시 코드 리팩터링

* 테스트 실행: Step 2에서 완성한 전체 인수 테스트를 실행해 모두 녹색인지 확인합니다.
* 애플리케이션 코드 리팩터링: 계층과 객체의 책임과 역할을 기반으로 유지보수하기 좋은 코드로 리팩터링합니다.

### 2. 신규 기능 빠르게 개발하기

* 신규 기능 설계: 기존 기능들 중에 보완하면 좋을 부분을 찾습니다. (AI의 도움을 받아도 좋아요 🤖)
* 인수 테스트 조립: feature파일에 신규 기능에 대한 시나리오를 작성하고 테스트를 구축합니다.
* 핵심: 모든 내용을 새로 만들기보다 Step 2에서 구축한 것을 재활용하여 테스트를 조립하세요.
